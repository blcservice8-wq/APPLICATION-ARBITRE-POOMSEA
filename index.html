Bienvenue

Cette application fonctionne entièrement dans votre navigateur Chrome, sans connexion internet ni serveur externe. Toutes les données (ASC, joueurs, photos) sont enregistrées localement sur cet ordinateur, dans la mémoire du navigateur.

⚠️ Important : pensez à utiliser le bouton « Exporter les données » régulièrement pour sauvegarder votre travail dans un fichier, et à le réimporter si vous changez d'ordinateur ou videz le cache de Chrome.
